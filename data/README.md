# Dataset

Download the Breast Cancer Wisconsin (Original) dataset from the UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/15/breast%2Bcancer%2Bwisconsin

Place the raw data file in this folder before running the training script, for example:

```text
data/breast-cancer-wisconsin.data
```

The repository ignores raw data files by default so the project can stay lightweight and avoid redistributing the dataset.
